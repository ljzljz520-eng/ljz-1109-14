# 广绣文化专题介绍网站

## 🛠 技术栈
- Frontend: 原生 HTML5, CSS3 (Grid & Flexbox), 原生 JavaScript (ES6 Modules)
- Assets: SVG 矢量图形, JSON Mock 数据
- Server: Nginx (Alpine)

## 🚀 启动指南 (How to Run)
1. 确保 Docker Desktop 已启动。
2. 在项目根目录执行：
```bash
docker compose up --build
```
3. 等待容器启动完成。

## 🔗 服务地址 (Services)
- Frontend: [http://localhost:3000](http://localhost:3000)

## 🧪 项目特性
- **响应式布局**: 支持移动端、平板与桌面端三套断点适配。
- **模块化架构**: 基于 ES6 模块组织代码，实现路由管理、数据加载与组件封装。
- **视觉设计**: 融合中国传统美学配色与现代 UI 交互，支持 3D 可视化针法演示。
- **性能优化**: 实现图片懒加载、滚动触发动画及低端设备性能降级方案。
- **纯前端实现**: 无外部依赖，数据通过本地 JSON 异步加载。

## 📖 传承的意义（专题长文页）
`pages/heritage.html` 按「岭南生活 / 外贸记忆 / 师承体系 / 进校园」四块切片讲广绣的文化传承意义，扫读优先（要点卡 + 一句话提要 + 可折叠深读），并提供：
- **可折叠段落**：每块 2 个深读段落，默认展开、可独立收起，折叠状态跨刷新保留。
- **引用来源与术语索引**：正文内联引用上标（链接到 9 条来源）与术语词条（链接到 14 条按拼音排序的术语表）；引文区分原文 / 转述 / 艺诀 / 馆方资料。
- **全文检索 + 节点偏移**：搜索命中折叠长文中的具体段落，结果带版块面包屑、上下文片段与「节点偏移」字符数，点击自动展开、平滑定位、高亮，URL hash（`#h-节点id-偏移`）可分享、可恢复。
- **版本链编辑**：编辑模式下正文 / 引文可直接改，保存即生成新版本；版本链支持预览与回滚（回滚生成新版本并保留 parentId 指针，历史不丢），数据存于 localStorage，内容结构升级时自动重新播种。
- **移动端目录同步与恢复**：桌面端常驻滚动监听目录（scrollspy + 阅读进度条）；移动端为悬浮「目录」按钮 + 底部抽屉，目录与正文滚动双向同步，抽屉开关与阅读位置跨刷新可恢复。
